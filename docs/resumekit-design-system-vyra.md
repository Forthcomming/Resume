# ResumeKit 设计风格文档

> 风格参考：直接借鉴 Vyra 设计语言。冷蓝雾气背景 + 白卡片浮层 + 衬线大标题 + 大数字指标。高端、克制、有呼吸感。


## 整体气质

背景基调是冷蓝雾气色，不是纯白也不是灰色。
白色卡片悬浮在这个背景上，形成明确的层次感。
大量留白，内容只占页面宽度的 55% 左右。
主标题用衬线字体，传递权威感和精致感。
数字指标做大做显眼，是页面视觉主角。
CTA 按钮只有一个，深色实心，其余操作全部退到次级。

## 阴影

```
卡片默认    0 4px 24px rgba(15,25,36,0.08), 0 1px 4px rgba(15,25,36,0.04)
卡片悬浮    0 8px 40px rgba(15,25,36,0.12), 0 2px 8px rgba(15,25,36,0.06)
数据悬浮卡  0 12px 48px rgba(15,25,36,0.15), 0 4px 12px rgba(15,25,36,0.08)
```

卡片整体带轻微白色边框：`border: 1px solid rgba(255,255,255,0.7)`
这是让白卡在蓝灰背景上"发光"的关键。

## 背景与氛围处理

页面底色用 #E8EEF5，不是纯白。
顶部 Hero 区域可以加一层径向渐变叠加，从中心略亮到四周略暗，增加雾气感：

```css
background: radial-gradient(ellipse at 50% 40%, #EEF3FA 0%, #D8E5F0 60%, #C8D8E8 100%)
```

内容区块之间的背景可以有微妙变化，比如第二个区块略深一点点 #DFE8F0，形成自然分层。

不要用纯色块切割区块，靠背景色的微妙渐变和留白来区分。

## 核心视觉规则

1. 背景是蓝灰雾气色，不是白色，这是整个风格的基础
2. 白卡片加轻微白色边框和阴影，让它在背景上"发光浮起"
3. 衬线字体只用于 Hero 和区块大标题，其余全部无衬线
4. 大数字是视觉主角，配合点缀色（绿、金、蓝），不要弱化它
5. 区块标签用方括号 + 全大写，放在标题上方作为内容分类锚点
6. 全站只有一个深色实心主按钮，其余操作都是次级样式
7. 留白要大，内容不要撑满页面宽度，密度感来自内容质量不是数量
8. Footer 用深夜蓝做强烈收尾，形成节奏感
