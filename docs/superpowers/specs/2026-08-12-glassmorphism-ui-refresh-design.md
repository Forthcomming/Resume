# ResumeKit 玻璃拟态 UI 改造设计

## 目标

在不改变信息架构、业务逻辑和交互流程的前提下，将落地页、仪表盘、设置页和简历编辑器统一为参考图所示的冷蓝雾面玻璃风格。

## 设计原则

- 保持现有冷蓝背景与深色文字体系。
- 使用克制的半透明、背景模糊、白色折射边缘和冷蓝阴影建立层次。
- 不使用霓虹外发光，不降低表单和正文的可读性。
- 简历预览纸张保持纯白，避免影响阅读、打印和 PDF 导出。
- 保留现有路由、文案、字段、组件结构与交互行为。

## 材质层级

在全局样式中提供三个可复用层级：

1. `glass-surface`
   - 用于顶部导航、页面主框架和落地页大型展示容器。
   - 透明度较高，背景模糊较强。

2. `glass-panel`
   - 用于简历卡片、设置面板、编辑器区块、弹窗主体。
   - 透明度适中，保持内容清晰。

3. `glass-control`
   - 用于输入框、下拉菜单、状态标签和操作菜单。
   - 更接近实色，确保交互控件对比度。

所有层级统一包含：

- 半透明冷白填充
- `backdrop-filter` 与 WebKit 兼容声明
- 1px 白色半透明边框
- 顶部内高光
- 低饱和冷蓝外阴影
- 浏览器不支持透明模糊时的实色回退

## 页面应用范围

### 落地页

- 导航、Hero 展示框、主要内容卡片、FAQ 与 CTA 容器采用统一玻璃材质。
- 保留当前内容顺序、品牌色与响应式布局。

### 仪表盘与设置页

- 顶部导航使用 `glass-surface`。
- 搜索框、简历卡片、新建卡片和设置表单使用对应玻璃层级。
- 菜单和确认弹窗使用 `glass-control` 与 `glass-panel`。

### 简历编辑器

- 顶栏与左侧编辑工作区增强玻璃层次。
- 编辑区块、版本选择器、JD 面板和 AI 弹窗统一材质。
- 右侧简历预览保持纯白纸张。

## 形状与交互

- 面板圆角统一为 16px 左右。
- 控件圆角统一为 10-12px。
- 主要按钮保持胶囊形。
- Hover 只调整边框、高光、阴影和轻微位移，不添加持续动画。
- 保留键盘焦点样式和现有可访问性语义。

## 实现边界

- 优先修改 `app/globals.css` 和 `tailwind.config.ts`，集中定义材质 token。
- 页面组件只替换表面相关 class，不重构业务逻辑。
- 不增加第三方依赖。
- 不修改简历数据结构、保存逻辑、AI 流程和 PDF 导出实现。

## 验收标准

- 四类页面具有一致的冷蓝玻璃材质语言。
- 背景色能透过主要面板被感知，面板仍保持清晰可读。
- 导航、卡片、输入框、菜单和弹窗之间存在明确材质层级。
- 简历预览和导出结果不受影响。
- 桌面和移动布局无明显溢出或错位。
- `npm run build` 通过。
- 仪表盘、设置页、编辑器和落地页完成浏览器视觉检查。
